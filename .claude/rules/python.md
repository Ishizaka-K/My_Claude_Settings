# Python Rules

- I/O、設定読み込み、ドメインロジックを分ける。
- アプリとして育てるコードでは `src/` layout を検討する。
- 型ヒントを使い、複雑なデータは dataclass などで構造化する。
- `if __name__ == "__main__":` は起動用に限定し、実処理は import 可能にする。
- 例外を握りつぶさず、原因調査に必要な情報を残す。
- 外部 I/O、時刻、乱数、ネットワークはテストで差し替えられるようにする。
- 依存関係は `pyproject.toml` などに集約する。
