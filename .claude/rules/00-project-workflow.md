# Project Workflow Rules

- 返答とドキュメントは原則として日本語で書く。
- 実装前に、対象範囲、変更方針、検証方法を短く確認する。
- 既存のファイル構成、命名、テスト方針を優先する。
- 秘密情報、認証情報、個人情報を出力しない。
- 破壊的操作、広範囲の削除、大規模リネームはユーザー確認なしに行わない。
- 設計、タスク、レビュー、実装ログは `docs/harness/document-storage.md` の構成に従って残す。
- レビュー指摘を修正しない場合は、理由とともに `docs/decisions/decisions-<run-id>.md` に残す。
