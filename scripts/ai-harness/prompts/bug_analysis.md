# Goal

報告された不具合の根本原因を特定し、証拠、影響範囲、修正方針を提示してください。

# Context

このプロンプトの後に、期待する挙動、実際の挙動、再現手順、エラー、ログ、関連ファイル、テストなどが添付されます。

# Constraints

- read-only で調査し、ファイルを編集しないでください。
- 確認済み事実、推論、未確認の仮説を分けてください。
- 対症療法ではなく、データと制御の流れを追って根本原因を調べてください。
- 単一ファイルだけで断定せず、必要な呼び出し元・呼び出し先・設定・テストを確認してください。
- 承認が必要な操作は行わず、失敗内容を報告してください。

# Done when

- 最有力の根本原因がファイルやコード箇所とともに示されている。
- 根拠が示されている。
- 代替仮説と、それを否定・確認する方法が示されている。
- 影響範囲と回帰リスクが示されている。
- 修正方針と必要なテストが示されている。

# Output format

```md
## Root Cause

## Evidence

## Alternative Hypotheses

## Affected Scope

## Fix Strategy

## Verification Plan

## Open Questions
```
